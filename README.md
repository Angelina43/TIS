# Облачное хранилище файлов (API)

![Project Banner](public/banner.jpg)

REST API для облачного хранения файлов с поддержкой загрузки, скачивания, переименования, удаления и гибкого разграничения прав доступа между пользователями.

## Возможности

* Регистрация и аутентификация пользователей по Bearer-токену (Laravel Sanctum).
* Загрузка нескольких файлов с проверкой формата, размера и автоматическим переименованием дубликатов.
* Управление собственными файлами (переименование, удаление, скачивание).
* Предоставление и отзыв прав доступа (`co-author`) для других пользователей.
* Просмотр списка собственных файлов и файлов, к которым открыт доступ.

## Стек технологий

* **PHP 8.2+ / Laravel 12**
* **Laravel Sanctum**
* **MySQL / MariaDB**

## Быстрый старт

```bash
git clone https://github.com
cd TIS
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
